# 가계부

브라우저에서 바로 쓰는 단일 HTML 파일 가계부입니다. 설치할 것이 없고,
내역은 Supabase에 저장되어 휴대폰 · PC 어디서 열어도 같은 내용을 봅니다.

## 사용법

**웹에서 바로 쓰기:** https://kbb7411-rgb.github.io/GGB/

로그인 없이 접속하면 바로 쓸 수 있습니다. 휴대폰에서도 열립니다.

**내려받아 쓰기:** [`index.html`](index.html) 파일을 내려받아 브라우저로 열어도 동일하게 동작합니다.
(같은 내역을 봅니다.)

## 기능

- **계절이 바뀌는 헤더** — 보고 있는 달에 맞춰 봄 · 여름 · 가을 · 겨울 테마로 바뀝니다.
  벚꽃잎 · 물방울 · 낙엽 · 눈송이가 천천히 흩날리고, 제목은 글자마다 떠올랐다 잔잔히 흔들립니다.
  계절에 따라 앱 전체의 포인트 색(장미 · 물빛 · 호박 · 청보라)도 함께 바뀝니다.
  (`prefers-reduced-motion` 설정을 켠 기기에서는 움직임이 모두 꺼집니다.)
- 수입 / 지출 입력 (날짜 · 구분 · 분류 · 내용 · 금액)
- 월별 보기와 월별 수입 · 지출 · 잔액 요약
- **달력 보기** — 한 달을 한눈에. 날짜 칸마다 그 날 쓴 분류 아이콘과 수입 · 지출 합계가 보이고,
  날짜를 누르면 그 날 내역이 아래에 펼쳐집니다. 「+ 이 날 추가」로 그 날짜에 바로 입력할 수 있습니다.
- **목록 보기** — 날짜별로 묶인 그 달 전체 내역. 달력 / 목록 선택은 다음에 열 때도 유지됩니다.
- **분류별 아이콘과 색** — 이모지 대신 직접 그린 단색 라인 아이콘 17종(밥그릇 · 컵 · 버스 · 집 ·
  지갑 …)을 씁니다. 분류마다 고유 파스텔 색이 있어 달력 · 내역 · 그래프에서 같은 색으로 이어집니다.
- **분석 — 분류별** : 그 달 지출의 분류별 비중 그래프
- **분석 — 전월 대비** : 지난달과 이번 달의 수입 · 지출 · 잔액을 같은 기준의 막대로 나란히 비교하고,
  증감액과 증감률을 함께 보여 줍니다. 아래에는 분류별 지출 증감이 변화가 큰 순서로 이어집니다.
  (지출은 늘면 빨강 · 줄면 초록, 수입과 잔액은 반대)
- 내역 수정 및 삭제
- **기기 간 동기화** — 휴대폰에서 적은 내역이 PC에서도 그대로
- 해당 월 내역 CSV 내보내기 (Excel에서 바로 열리는 UTF-8 BOM)
- 라이트 / 다크 파스텔 테마 전환
- 모바일 반응형 레이아웃

## 데이터 보관

입력한 내역은 [Supabase](https://supabase.com) 데이터베이스의 `entries` 표 **하나**에 저장됩니다.

| 열 | 뜻 |
| --- | --- |
| `id` | 내역 고유 번호 (uuid) |
| `date` | 날짜 |
| `type` | `expense` 또는 `income` |
| `category` | 분류 이름 |
| `memo` | 내용 |
| `amount` | 금액 (원 단위 정수) |
| `created_at` | 입력 시각 |

> ⚠️ **로그인이 없는 공용 가계부입니다.**
> 위 주소를 아는 사람은 누구나 내역을 보고, 고치고, 지울 수 있습니다.
> RLS 정책도 익명 사용자에게 조회 · 추가 · 수정 · 삭제를 모두 열어 두었습니다.
> 남에게 보이면 곤란한 내역은 넣지 마세요.

- 인터넷 연결이 필요합니다. 저장 · 수정 · 삭제에 실패하면 화면 위쪽에 알림이 뜨고,
  화면은 서버 내용 기준으로 다시 맞춰집니다.
- 테마 · 달력/목록 선택 같은 화면 설정만 브라우저에 남습니다.

### 예전 localStorage 내역

이전 버전에서 이 브라우저에 쌓아 둔 내역이 있으면, 처음 열 때 **서버로 옮길지 한 번만**
물어봅니다. 옮기든 옮기지 않든 원본은 `ggb-ledger-v1-backup` 키에 백업으로 남고 다시 묻지 않습니다.

## 기술

빌드 과정이 없는 단일 HTML 파일입니다. 외부 라이브러리는 CDN에서 불러오는
`@supabase/supabase-js` 하나뿐입니다.
