# 가계부

브라우저에서 바로 쓰는 단일 HTML 파일 가계부입니다. 서버도, 인터넷 연결도, 설치도 필요 없습니다.

## 사용법

**웹에서 바로 쓰기:** https://kbb7411-rgb.github.io/GGB/

설치 없이 접속해서 그대로 사용할 수 있습니다. 휴대폰에서도 열립니다.

**내려받아 쓰기:** [`index.html`](index.html) 파일을 내려받아 브라우저로 열어도 동일하게 동작합니다.

## 기능

- **계절이 바뀌는 헤더** — 보고 있는 달에 맞춰 봄 · 여름 · 가을 · 겨울 테마로 바뀝니다.
  벚꽃잎 · 물방울 · 낙엽 · 눈송이가 천천히 흩날리고, 제목은 글자마다 떠올랐다 잔잔히 흔들립니다.
  계절에 따라 앱 전체의 포인트 색(장미 · 물빛 · 호박 · 청보라)도 함께 바뀝니다.
  (`prefers-reduced-motion` 설정을 켠 기기에서는 움직임이 모두 꺼집니다.)
- 수입 / 지출 입력 (날짜 · 구분 · 분류 · 내용 · 금액)
- 월별 보기와 월별 수입 · 지출 · 잔액 요약
- **달력 보기** — 한 달을 한눈에. 날짜 칸마다 그 날 쓴 분류 아이콘과 수입 · 지출 합계가 보이고,
  날짜를 누르면 그 날 내역이 아래에 펼쳐집니다. 「+ 이 날 추가」로 그 날짜에 바로 입력할 수 있습니다.
- **목록 보기** — 날짜별로 묶인 그 달 전체 내역. 달력 / 목록 선택은 다음에 열 때도 유지됩니다.
- **분류별 아이콘과 색** — 이모지 대신 직접 그린 단색 라인 아이콘 17종(밥그릇 · 컵 · 버스 · 집 ·
  지갑 …)을 씁니다. 분류마다 고유 파스텔 색이 있어 달력 · 내역 · 그래프에서 같은 색으로 이어집니다.
- **분석 — 분류별** : 그 달 지출의 분류별 비중 그래프
- **분석 — 전월 대비** : 지난달과 이번 달의 수입 · 지출 · 잔액을 같은 기준의 막대로 나란히 비교하고,
  증감액과 증감률을 함께 보여 줍니다. 아래에는 분류별 지출 증감이 변화가 큰 순서로 이어집니다.
  (지출은 늘면 빨강 · 줄면 초록, 수입과 잔액은 반대)
- 내역 수정 및 삭제
- 해당 월 내역 CSV 내보내기 (Excel에서 바로 열리는 UTF-8 BOM)
- 라이트 / 다크 파스텔 테마 전환
- 모바일 반응형 레이아웃

## 데이터 보관

입력한 내역은 브라우저의 `localStorage`에 저장됩니다.

- 새로고침하거나 브라우저를 닫았다 열어도 내역이 유지됩니다.
- 데이터는 이 기기의 해당 브라우저에만 저장되며, 어디로도 전송되지 않습니다.
- 따라서 다른 기기나 다른 브라우저와는 내역이 공유되지 않습니다. 옮기려면 CSV로 내보내세요.
- 브라우저 인터넷 사용 기록 삭제 시 함께 지워질 수 있습니다.

## 기술

의존성 없는 단일 HTML 파일입니다. 빌드 과정이나 외부 라이브러리를 쓰지 않습니다.
